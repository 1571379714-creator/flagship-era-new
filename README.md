# 旗舰元年 · Flagship Era

**手机公司经营主题的大型德式桌游｜当前归档基线：6.0「产品平台与开放市场」首测版**

6.0 是一次结构重构：玩家以工作点组织采购、研发、定型、生产、合同与设施，主动预热推动共同发布，在有限订单与公开参考机的竞争中取得收入或科技成果。它不是可与 5.x 卡牌混用的补丁。

适合 2—4 人。6.0 尚未完成充分多人实桌平衡验证，游戏时长也未实测确认。

## 6.0 的核心结构

- 每位玩家每个本人回合分配 3 个工作点；共同发布仅由玩家主动预热推进。
- 参考机每代随机公开 1 款，四个市场数值和挑战奖励均印在同一张参考机上。
- 型号由四部件直接定型；配件与部署持续占用至退市，生产先付成本、销售后才取得实际收入。
- 参考机竞争要求真实零售成交；挑战奖励需要严格胜出，每家公司每场最多领取一次。
- 收入达到 60 或科技达到 30 触发最后阶段；全员各再进行一个完整回合后最终发布，比较收入与科技 ×2 的较高者。

完整 6.0 卡组为 **243 种设计、315 张实体卡**，包括稳定供货、定制整合、初始部件、研发、合同、设施、产品方案、参考机与需求。具体规则和卡面以 6.0 归档文件为准。

## 校验与重建

核验 6.0 原始交付内容不需要排版依赖：

```bash
cd versions/6.0
python work/verify_delivery.py
```

阅读或打印现有成品无需重建。若要重新导出，请在独立工作分支或副本中操作，并先阅读 [6.0 README](versions/6.0/README.md)。`work/make_data.py` 是初次迁移/写作脚本，会覆盖手改数据，不能作为日常构建命令。重建还需 Chromium、LibreOffice 与中文字体，且不同环境可能改变 PDF 分页。

## 协作约定

设计讨论、已确认规则和未验证参数必须分开记录。没有明确修改授权时只讨论，不修改规则或生成新版；已发布的版本快照必须保留不动。仓库保持私有，未指定开放许可；不得擅自公开、添加许可或上传字体、凭据、个人备份及无关聊天内容。
