# 旗舰元年 · Flagship Era

**手机公司经营主题的大型德式桌游｜当前归档基线：5.0「五厂协同」测试版**

收集配件、争抢公开供应链、秘密组装新机，并主动推动共同发布；揭晓时通过产品、定价与卡牌组合争夺四个市场。

“大型”强调策略与卡牌内容丰富，而不是叠加繁琐的程序。适合2—4人，90—150分钟是待验证的时长目标。**尚未完成充分多人实桌平衡验证。**

本仓库从5.0开始留存版本，不从头重构游戏，不把旧版本重新标成5.0。本次归档保留原始5.0交付文件的字节内容，新增的仓库文档只整理项目说明、设计决策与后续协作流程。

## 5.0的核心结构

- 五种行动卡在强度1—5间轮转：调研、研发、组装、合作、营销。
- 分代公开供应链形成抢购；稳定配件可重复使用，定制配件秘密筹备且使用后消耗。
- 大众消费、电竞娱乐、摄影创作、商务办公四个市场，秘密定价同时影响收入和现金。
- 性能、影像、轻薄、续航、折叠、生态六种类别，与红、黄、蓝、绿、黑五厂分别统计。所有玩家都可以积累五厂，不是固定阵营。
- 收入0—100与科技0—36相向排列。科技0→8每步对应2个收入格，8→36每步对应3个收入格，以同一玩家的两个标记相遇或越过判定终局。

> 当任意玩家的两个标记相遇或越过，完成当前回合的全部结算后，所有玩家各再进行一个回合，随后举行最终发布并计分。秘密终局目标只在最终计分时加入，不会提前触发游戏结束。

完整卡组为**302种设计、374张内容牌**，包含96张企划、41张科技、41张企业、80张稳定配件、64张定制配件、16张初始配件、12张基础项目、6张专项项目和18张目标。行动卡、定价牌和标记另计。具体卡面与规则以本版本文件为准。

## 重建与校验

仅验证归档完整性，不需要安装排版依赖：

```bash
python tools/verify_archive.py
```

阅读或打印已有成品不需要重建。重新导出前先复制到工作分支/工作副本，并阅读[5.0原始README](versions/5.0/README.md)。已发布快照应留存不动。

```bash
cd versions/5.0
python -m pip install -r requirements.txt
python work/build_all.py
```

上述生成还需要系统Chromium、LibreOffice和中文字体；没有随包分发字体。**不要在保留手改数据的情况下运行`revise_v50.py`或`make_rules_v50.py`，它们会按旧底稿重新生成JSON/正文。** 固定交付PDF可能与其他机器重建分页不同。

设计讨论、已确认规则和未验证参数分别记录。没有明确修改授权时只讨论，不直接改规则或生成新版本。每次实际修改应同时检查数据、规则、图鉴、版图与实体组件，保留旧编号与版本追溯。

目前没有指定开源许可证；本次导入不添加任何开放授权条款。芯片型号和五厂图标的资料与抽象边界见原交付说明。外部素材与商标授权没有在本次归档中重新审查。
