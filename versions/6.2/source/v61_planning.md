# 旗舰元年
## 6.1 设计规划书
发布悬念与实体操作 · 从6.0继续，不重构经营骨架

## 01 本轮目标与基线
GitHub仓库1571379714-creator/flagship-era-new的main已更新至6.0，本轮读取提交5ea3143af4da5225fcddd5c37349a21143fb3aea。数据、规则、规划的Git blob与本地6.0交付包一致。6.0快照保留，新内容另放6.1。

用户本轮要求三件事：更容易理解的规则语言，并可把例子和关联规则放侧栏；参考机在发布现场揭晓，奖励不只加收入或科技；减少纸笔记录，以卡牌和token表达状态。这是本轮改动范围，不再次更换收入／科技终局和工作点体系。

3工作点、4型号、真实库存、有限订单、公开需求、收入60或科技30触发及取高值计分继续沿用。所有213种非参考内容牌保留6.0的原始数值、费用、前置和能力；30张V新增特色奖励。243种设计、315张实体内容牌不变。

## 02 把随机性移到揭晓，而不是制造无边界惊吓
需求卡继续整段准备期公开：预算、订单数量和偏好仍是可规划信息。参考世代在准备期开始标定，期间即使供应换代也不变。玩家可以查图鉴，知道六种可能情况，但不能知道本场具体哪一款。

全部人锁定价格、实际批次分配、额外市场许可和推荐章后，才把该参考世代全部六张混洗，抽一张全桌共用。每场都混回已见过的卡，允许连续出现同一机型。这样，抽到第五次以后不会只剩一张已知竞品。最终发布也如此。

保留一市场一份虚拟订单与严格胜出、真实零售条件。参考机不会回收玩家资金、突然销毁产品或改动顾客预算；它只影响一份订单的竞争位置及挑战机会。

这会增加不确定性，但不能逻辑上保证堆最高规格永远最好。高吸引力提供更大容错，低成本押注与高价风险仍应有空间。推荐章可能成为下一场保险，但不能绕过预算或无库存。必须实测随机波动是否太强，不能只因规则完整就断言动机已经实现。

## 03 奖励有不同用途，也保持两条主线入口
1／2／3星仍可选2／4／6收入或1／2／3科技。每张参考机额外提供一种特色奖，三选一而不是三份一起领。零星任何形式都无奖；选星数必须与实际赢过的市场格一致。

| 机型定位 | 特色奖 | 经营用途 |
| --- | --- | --- |
| 基础通讯 | 8／16／24现金 | 回笼研发与生产资金 |
| 均衡主流 | 从公开研发／商业选1／2／3张 | 根据当下牌市转向下一阶段 |
| 电竞性能 | 一个已有在研加1／2／3进度 | 用真实首发测试推动工程成果 |
| 影像创作 | +2／+4／+6推荐章 | 为以后一次指定市场投放增加竞争余量 |
| 商务折叠 | 现在购1公开配件，减0／3／6取得费 | 抢到当场存在的供应，不凭空复制资源 |
| 全能旗舰 | 1／2／3批试产券 | 以后省工作点试产，仍承担全部制造与产能限制 |

科技奖与工程试验都要求本场首发并已部署研发，防止旧机在降价销售中一再被认定为新技术成果。奖励进度不触发工作点实验室加速，不能立项或把余量转给别的项目。

工程试验在本场交易完成后、合同期限结算前处理，因此可完成尚有效的验证委托。新成果不回改已锁定的资格、订单或回收。供货引荐是即时配件交易，不触发同一工作点采购两件或后台查堆等能力。

两种留存奖励每公司分别最多1件，实体上只有“推荐章”和“试产券”两个保留位。再次取得二选一，不叠加、不累计成新货币。已投入的推荐章即使没卖出也消耗；试产券一次用掉，未用批数不保留。终局不把它们兑换分数。

## 04 从记数改成摆放，并不删除经济约束
6.0正文已经写了不使用纸笔，但有些操作仍用“记录应得现金”“记录投放批数”一笔带过。本版给每一项真正需要延续的状态指定实体载体。

| 状态 | 实体表达 | 何时清除 |
| --- | --- | --- |
| 已生产库存与投放 | 同一批次块在型号、合同、零售和留库格移动 | 售出并领取后回储备；未售归型号 |
| 当场成交证据 | 原市场格分待售／已售，卖出块先不移走 | 挑战与触发条件确定并收款后 |
| 研发工期／待证据 | 进度条0—4及待验证片 | 项目完成或放弃 |
| 合同期限与押金 | 2枚期限片；真钱压在合同代银行保管 | 发布减期限；完成退押，失败押金入银行 |
| 平台已用配额 | 用量条附在真实芯片上 | 实际发布结束；退市或移交不清零 |
| 一生一次验证 | 型号面板的已验证片 | 该型号真实退市 |
| 每回合／每期能力 | 不同文字的已用片压在来源卡上 | 下次本人回合／发布整理 |
| 调校、额外市场、共用链接 | 源卡标记、市场片、带方向编号的共用片 | 合法改款、结束本场或解除共用 |
| 待结成果与挑战 | 来源牌上的待结片、已售格的星级与选择片 | 领取后移除 |

不为每批货记录成本历史：制造时实际付费，成交不返还成本，退市残值也是固定规则，根本不需要追溯。旧配置保留真实卡，不抄一次再归还资源。库存数量用实际方块，不再同时维护同数值滑块和分配表两套账。

逐笔收款是操作优化：全桌先冻结所有成交及资格，再按块收钱、移动主线标记并归还块。依旧不让先收到钱的人在本场补生产或重排合同；在本轮卡组范围内，逐笔与原同时收款不改变应得总额。T41转换在收款前盖在具体已售块上，防止两条主线同时领。

## 05 规则书的阅读设计
正文采用“你做什么、花多少、做到哪一步”的完整短句；首次出现的词立即解释。相同信息只设置一个权威章节，其他地方用§交叉引用。

右侧固定为例子、实体摆法、易错点与关联规则。必须执行的条件仍在正文，不能把“科技奖还需首发”只藏在例子里。Word使用可编辑正文与侧栏，HTML在窄屏把侧栏移到对应段落下方，不要求来回翻两份文件。

规则不追求最少页数。用合理字号和留白替代把四个裁定塞成一行。价格牌补1—4批的现金／收入小表，合同卡补整单总额，研究卡与期限条提供实物提示；这些派生数字不是新收益。

图鉴、版图、参考机正反面打印包、通用组件同步更新，不允许正文写现场抽，中央版图仍要求提前亮参考。参考机同代背面相同，只露世代，不露定位、强弱或奖励。

## 06 首测任务与保留风险
先用2人测参考机公开改隐藏后的价格选择、实际成交数和主动预热意愿，再测3／4人的结算时长。使用完整卡组，不假定每局看到全部牌。

要区分“产品力更高仍可能卖不出”和“高产品力完全没有价值”。前者可能来自预算、投放错误或供给过多，不应直接归因于参考机。记录击败参考但被真人挤掉订单的情况，确认挑战不会给没卖出的产品送分。

奖励重点看：工程试验是否让研发路线过快；推荐章是否形成高星连续滚动；试产券能否创造取舍而不是空有数量；现金和牌市奖励是否有被选择的机会；最终发布是否又只剩固定主线加分。

实体重点看：玩家是否真正不拿纸笔；未售块是否留回正确型号；合同与零售是否会重复使用一批；平台用量是否在退市时被误清；推回合与推发布的重置片是否混淆。必要时先改版面，不加新规则。

本版没有真人多人实桌、隐藏信息策略代理或全卡连锁穷举。对原作与现实芯片没有新增事实研究。数据、程序情境和印刷几何检查不能证明平衡、90—150分钟实际时长或打印机套准。
