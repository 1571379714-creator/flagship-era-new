01 一批手机，从组装到卖出

用统一牌市取得配件、研发、合同、设施与方案。把一组完整配置做成一批现货，先付款，再等待玩家共同推动的发布会。

1.1 产品位里放的，就是一批货

一个产品位只代表一批已经付费、尚未成交的手机。没有“空型号再生产库存”的两层结构，也不需要记录同型号有几批。

组装一次就产生一批。相同配置想再造一批，要另花工作点、另付款，占另一个产品位。所有产品均可争订单；不是每家公司只派最强一款。

一批货只去一个零售市场、一张合同，或留库。未成交的保持完整配置等待下场；也可在自己回合主动取消。没有新旧代龄、自动减分或强制到龄退市。

例子 / 摆法

1号位一组配置＝1批。2号位再摆一组，即使配置完全相同，也要付第二批制造费。

1.2 钱、收入和科技，分别拿

现金用于入库、组装、研发与经营；收入是实际成交等商业成果；科技是研究与验证成果。三者不能随意互换。

收入达到60，或科技达到30，任意一项即可触发最后阶段。先完整结算当前玩家回合，再让所有玩家各做一个回合，最后共同发布。

最终成绩比较收入与科技×2，取较大的数；同分比较另一项，再比现金，仍同则并列。没有秘密终局目标。详细时序见§13。

例子 / 摆法

卖出28价一批：拿28现金，再前进2收入。拿钱不是移动收入；研发得科技也不是拿钱。

1.3 发布时间由玩家决定

每次轮到你，有3个工作点。你选择工作顺序；其中可以花1点预热，自选推进发布轨1—3格，每本人回合至多一次。

发布轨到终点，当前玩家做完剩余工作后立即共同发布。没有固定轮数，也不在全桌轮过一遍后自动结算。

“两次发布之间”叫准备期，卡牌上的每期／每周期都指它。合同期限只按实际发布减少。

例子 / 摆法

工作点每个本人回合恢复；合同期限每场发布减少。未售产品不会随其中任何时钟老化。

2.2 摆公共区和玩家区

随机决定先手，顺时针回合。主牌洗混，翻8张；旁边留主弃牌堆与移出区。N01日常换机作为首场需求，其余11张洗好。供应世代与本场参考世代均置I。

发布轨从0开始：2人终点12，3人16，4人20。

每人主牌抽8留5，其余进主弃牌。手牌上限8。每人4个产品位、2在研槽、2合同槽、3格设施空间；相关设施按卡面例外。

例子 / 摆法

初始部件入库免费；要用它们造第一批，仍须花组装工作并付款。8抽留5是本版统一牌流的首测设置。

2.3 看得到什么，不用记什么

公开现金、双成绩、工作点、四栏稳定库及其锁定、研究与进度、已完成技术、设施、合同、已占产品位数量、需求和两种世代。

手牌、尚未揭晓产品的定制与配置、技术指派的产品号、价牌与投放去向保密。代替卡引用了哪些种类公开，但未必公开它们在哪个产品位。已公开产品以后配置继续公开。

不要记年龄、历史价格、历史制造费、销量总账或平台用量。产品区的完整卡组与一个去向片就是现货状态。

例子 / 摆法

稳定芯片在库里公开；别人知道它有产品引用，因此你不能悄悄换掉它。哪个产品用它，可以先保密。

先取消2号产品，安装新影像，再在2号组装，是合法顺序；取消不让你把已经付掉的现金拿回来。

3.2 一个完整回合怎样结束

回合开始恢复3点及“本人回合”限次。按你选的顺序执行工作和即时效果，钱或点不够就不能开始。

结束工作后：手牌弃至上限 → 若发布到顶则完整发布 → 处理本回合待开放的新世代 → 检查最后阶段 → 下一人。

预热到顶不会打断你剩余工作，但不再给其他人响应回合。达到收入／科技终局线，也先完成本回合已触发的发布。

U02专用组装点是明确例外：每本人回合一次，只能正常组装1批，不是多一个完整回合。

例子 / 摆法

发布差3格，你先预热，再用剩余2点各组一批。随后全桌锁价；别人不能要求先补一次组装。

04 一个主牌堆，五代卡都能拿

4.1 先选完，再补一次

一次取牌工作可取得至多2张：每张选当前公开牌或主堆顶盲抽，可以混选。稳定与定制取得时都不额外付钱，与其他主牌一样先入手并占手牌。

本次选择期间，牌市空位留空，不左移、不补新牌供本次再挑。全部选完后才从主牌堆一次补满空位。任何连续取牌奖励也按整个奖励结束后补一次；纯取牌不等于安装、立项或签约。

主牌堆空时，仅洗主弃牌；库内牌、在研、已完成、合同归档、产品中与移出区都不能补入。无牌就只拿实际存在的数量。

例子 / 摆法

拿走牌市2号和6号，只在两张选完后补两个空位。未来五代配件照样可以拿到手里。

4.2 换代只开放使用，不再加牌

全桌首位科技达到3／7／13／20，依次开放II／III／IV／V代，回合末生效。跨多个门槛直接到最高对应世代，不洗新包、不换商店。

所有将用于组装的配件和Q方案，其印刷世代不得高于当前供应世代；不能凭已取得、已入库或研究领先跳过。本版所有主牌均给出世代，必须使用6.2卡面，不能混用6.1旧效果。

本准备期的参考世代不随中途换代提高；普通发布结束，先处理新世代，再标定下场参考世代。只标代，不提前翻参考。

例子 / 摆法

现在II代，库里可付费装V代芯片，但不能用它造机或作验证样机。其他产品可以改用已开放的定制芯片。

05 稳定库四栏：实体不动，产品用代替卡

5.1 拿到和入库，是两件事

芯片、屏幕、影像、机身各只有一个稳定栏。初始卡也占相应栏，不是额外备用库。

安装工作从手牌选1张稳定件，付卡面入库费，替换同类旧稳定件；不能把稳定卡绕过入库直接装进产品。旧稳定进主弃牌，初始S撤下则移出，不退费用。定制不装进稳定库。

非初始稳定本版入库费直接印9；初始0。未来世代允许入库。某栏有引用时不能撤下、替换或临时挪动，即使新卡同编号也不行。

例子 / 摆法

花一个取牌工作拿到两张稳定，不代表已经安装两张。还要分别安装和付款；T36才许可一个安装工作处理两类。

5.2 每类代替卡读取同一库栏

产品里每使用一种稳定来源，就放对应“稳定部件·种类”代替卡，读取本人库栏实体的规格、功耗／供电、制造费及效果。稳定实体始终留库。

不同产品可同时引用同一栏；每批分别付款，不复制实体厂标、不另记芯片配额。代替卡不是主牌，不占手牌，不可卖弃。多项定制只能整张用，不能和代替卡覆盖同一部件。

只要仍有任何产品引用这种代替卡，该栏就锁定。 不需额外锁定计数器；看仍在产品中的代替卡即可。

例子 / 摆法

1号、2号都用稳定芯片。取消1号后仍有2号，所以还不能换芯片；2号也结束占用后才能换。

5.3 何时解除引用

取消产品时，收回该产品的代替卡；其他产品引用不受影响。

成交或出口的产品，要等本场全部奖励和证据检查完毕，才统一收回代替卡与技术。发布中即使某批先收款，也不能趁机换库卡改变后面产品。

未成交或主动留库的产品，引用一直保留，跨发布不复位。你不能将代替卡先拿走、却声称产品仍拥有那块部件。

例子 / 摆法

不必把稳定实体从产品搬回库：它从来没离开过。需要收的只是代替卡与指派片。

06 一次组装，直接做出一批

6.1 配齐四类，再验收付款

花1工作点选择空产品位，恰好配齐芯片、屏幕、影像、机身。每项来自同类稳定代替卡，或来自实际定制卡。整张定制的全部部件必须同批使用，不拆、不错位、不重叠。

可以加至多1张手中Q方案、部署通常至多2张已完成技术。检查实际世代、折叠配套、影像兼容、技术占用与Q前置；全部合法、现金足够才付款组装。

这次完成时就是1批现货。 不再另外付工作进行生产，不叠加数量到已有产品位。没有Q也能造机。一般用最小空位编号，位置不随意移动。

例子 / 摆法

三项定制若含芯片、屏幕、影像，只再放机身代替卡。不能同时加一块更好的影像弃掉定制里的影像。

6.2 功耗与特征直接看卡

芯片、屏幕、影像各自有效功耗＝印刷功耗＋所选调校增量−本机减免，各项最低0。三项相加不得超过机身有效供电；供电余量就是两者之差。

折叠屏和折叠机身必须成对。高级影像读取其印刷兼容要求；T26、T38、C06等只免除明确兼容条件，不跳过世代与供电。

基础竞争力＝四项规格之和＋明确通用修正，最低0。不含价格、市场偏好、渠道加分；不存在年龄扣分。调校只有一种，必须在组装时选定，有成本就全部承担。

例子 / 摆法

规格6＋5＋6＋2＝基础19；若技术只加电竞3，基础仍19。印刷数字随卡摆放即可复算，不用留历史记录。

大众消费接受所有合法产品；电竞通常需性能，摄影需影像，商务需续航／生态／折叠之一。卡牌可以放宽。安全与耐候仅为合同资格。

例子 / 摆法

同一产品可能合格于三个市场，但只有一批货，锁定时仍只能选择其中一处。

6.4 组装费、部件费、方案费

组装时一次结清：四项印刷制造费＋有效组装费＋Q方案费−明确总费用优惠，最终至少6现金。

基础组装费直接印8；它合并了6.1的开发费6与装配费2。只减“组装费”的能力先把这8减到最低0，再加部件和Q；总费用减免最后应用。

没有随世代变化的成熟折价。入库费另付，不计入本批费用，也不是制造预付款。相同稳定卡给两批供货，每批都支付它的制造费。

试产券只改变它印出的那一次组装；仍恰好1批、照查空位、世代与资金。

例子 / 摆法

初始四件制造费合计5，无Q与优惠：本批付5＋8＝13。120减13剩107。取消不退13。

07 取消、改款与跨场等待

7.1 取消是收回配置，不是退款

在自己正常工作阶段，可免费取消一批尚未成交产品。已付现金、工作和领取过的科研成果不退；这不触发销售、清仓或挑战奖励。

定制配件整张回手，Q回手，代替卡收回，部署技术释放，产品位清空。稳定实体留库。手牌超过上限可暂留，但回合末要弃牌。

发布锁定开始后，不可取消、修改配置或换库。看到参考机再撤销不被允许；只能等下次轮到自己。

例子 / 摆法

取消一批双项定制产品，双项卡整体回手，不留一项在原位。释放技术不把已完成研发变回未研究手牌。

7.2 改款＝取消，再组装

基础规则不单设改款动作：先取消，再在空位组装一批新配置，重新检查世代、合法性并付完整费用。没有无库存型号可以免费补产。

T31、U14明确奖励“取消后紧接同一产品位组装”的操作，按卡面限次；中间执行其他工作，就不能追溯这次取消取得优惠。先确认能重新造好再决定取消，但不退已完成取消。

同配置重复造货必须使用另一个空位；定制需要另一实体，完成部署技术也不能同时指派两批。稳定代替卡可重复引用四栏。

例子 / 摆法

不能取消后把“本回合已用”片也拿走，重拿U11首次优惠。改款没有刷新研发、合同或世代验证次数。

7.3 未售原样留下，成交则结束

未售或留库产品不减分、不回手、不再付款，下一场可重选价格和去向；它持续占产品位、定制、技术以及稳定栏引用。没有老机型这一身份。

成交的产品在整场奖励结束后清空：定制和Q移出，代替卡收回，技术释放。Q21只让自己Q回手，定制仍消耗。没有免费残值回款或旧型号档案。

H29出口是有卡牌许可的另一种处置：取得卡面现金并按成交清空，不能同时按免费取消回收定制；出口不触发Q21等成交奖励。

例子 / 摆法

同一批没卖掉，两场之后还是同样的配置。若卖掉了，下一场要卖同款，必须重新花点、付款、组装。

08 研发与证据：不记录产品历史

8.1 从手牌立项，投入工期

只从手牌立项T，不再直接使用独立研发区。花1工作点，先满足此前完成项目数，付全部研发费，占在研槽并推进1格。

以后每1工作点给一个项目加1格；可以同回合连续投入。到印刷工期且满足证明条件，就领取印刷科技、移到完成区。每实体T只完成一次，不因部署、释放或取消再次领奖。

到线缺证据放待验证片；以后花1工作点复核。额外进度不溢出，实验室只在其规定的普通推进时触发。本人回合可免费放弃未完成项目，费用不退、牌进主弃牌。

例子 / 摆法

工期3：立项有1，再推进2次可完成。缺样机就停在3，不是先拿科技再补证明。

8.2 用现货或临时样机作证

可公开现存合法产品作为证据；也可用自己当前库内已开放稳定件、手中已开放定制及未部署的完成技术临时拼样机。临时样机不花组装费、不产货、不参加销售，展示后原位归还。

稳定供货可以被产品与临时样机共同引用；但定制实体及部署技术不能重复占用。需要两样机时须同时合法；稳定可共用，定制与部署仍各需实体。

不能使用未来世代、对手资源或正在完成的项目证明自身。要求真实已生产产品的独立验证不能用临时样机替代。

例子 / 摆法

8.3 工艺与部署的区别

工艺研究完成后作用于公司，不占产品技术槽。部署能力必须在组装时分配给产品才生效；通常每批2槽，T21可扩到3且自身占1，不能叠到4。

技术牌留公开完成区，用扣住的产品号指派片表示占用；一张部署技术同一时刻最多一批。取消或成交整理释放，未售跨场继续占用。

研究新技术不会自动增强已经组装的货。要加技术就取消重组；发布奖励新完成技术也不能追溯本场配置。

例子 / 摆法

T37的共享已经是基础规则；它现在降低同平台再次组装的费用，而不是解锁稳定引用。

8.4 独立验证按公司和世代限次

花2工作点、12现金，公开一批现存合法产品，通常要求基础竞争力≥10、至少2种特征，获得1科技。

每公司每个当前供应世代至多一次，在公司面板该世代格放永久已用片。不能回头补领低代验证；跨多个世代只在当前代执行。取消、重组、成交、更换产品号均不复位。

T32改变验证门槛，T39减工作，U12／Q22减现金，均不增加次数。技术服务每本人回合一次：无完成T得6现金，有则10，U18改16；服务不加收入科技。

例子 / 摆法

09 合同与设施围绕实际批次工作

9.1 签合同，押金直接放真钱

9.2 两批订单由两个产品位交货

锁定时把各产品的去向片指向同一合同A/B/C；交货不占零售订单，不受顾客预算或参考机影响。按卡面印好的整单现金、收入与押金结算；Q18等逐批例外另算。

例子 / 摆法

9.3 设施与限次放在来源卡上

从手牌建设U，付同一回合2工作点、印刷费用和空间，建成后生效，不补领过去优惠。可在本人回合免费拆除，移出且无残值。

每本人回合／每期能力分别在来源卡上放相应已用片，到规定时点才复位。取消不复位；试产券不是正常组装工作，不触发只写正常组装或工作点的能力。

例子 / 摆法

例子 / 摆法

最多4个现货位，最多4枚投放号片。一批选合同就不参加任何零售市场；留库不比较名次。

10.2 发布时现抽，不提前猜中

本场需求和参考世代预先公开。所有人锁定后，揭晓玩家配置、价格、去向，再把标定世代全部6张V洗匀现抽1张，全桌共用。

每场都放回全部6张再抽，允许重复；不得预看、挑选或重抽。参考每市场最多占1订单，它的数值已经完成计算，不再叠价格、偏好或玩家预算。

中途供应换代不会改变本场参考世代；最终发布也照常锁定后现抽。

例子 / 摆法

10.3 放错或配置违法

漏价、多价按28；无48资格却选48按38，不重选去向。去向漏放按留库；揭晓后发现一批多放去向，整批留库，不选择对自己最有利的一处。

无市场资格或超预算，该批本场不能成交，原样保留。合同不满足整单条件则都保留，不改投。

若产品配置自身违法（未来件、超功耗、重复定制／技术、库引用错误等），本场不能成交、证明或挑战，卡留原位待下次本人回合取消；不得现场免费改配置。

例子 / 摆法

错放价格不是一次看到参考机后降价的机会。开局演示时先练习一批只放一个去向片。

12.1 先确认结果，再逐笔领取

⑤全桌按触发者下一位起，先合同再产品位顺序领取现金、收入与普通成果；再同顺序处理已选特色奖。

13 最后阶段、速查与测试边界

13.1 所有人各再一个回合
