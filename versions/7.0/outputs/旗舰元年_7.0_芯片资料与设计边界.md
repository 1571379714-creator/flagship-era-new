## 不改变的界限

现实芯片制造商与五家虚构供应商分开。稳定可以重复供应；定制是游戏工程方案，不宣称现实中芯片厂可任意向所有公司授权。芯片与影像不印无意义直板；屏幕/机身的直板/折叠继续参与配套。

大多数负载3–6，少量高负载7–8；本轮不重新普降或抬高负载，不改机身供电来凑合法。比较芯片要控制屏幕、影像、机身与科研配套，同时也看实际套装绑定的差异。代际优势通过更高主要规格表达，旧平台以逐批成本、已有供应关系及专长保留价值。

没有建立定期检索或监测任务。新的硬件信息由用户另行提出后再核实。
