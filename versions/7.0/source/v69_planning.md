# 6.9 五十平台与芯片专长

## 01 延续，而不是再换一套游戏
以6.8真实交付为底稿。保留指定的骁龙12、曦力／天玑9、苹果10、麒麟7、玄戒2，合计40；补充猎户座6、谷歌2、展锐2，得到50个不重复芯片。每代4稳定＋6含芯片定制；不删芯片卡，不加副本，不拆已有套装。

主牌257张、内容牌315张、初始通用配件16张均不变。稳定80、定制64仍全部独立。初始四套按原规则免费入库，制造仍须付款；主牌芯片名单不包含这四张通用芯片。

## 02 真实名字与游戏方案分开
苹果一至六代写A11 Bionic、A12 Bionic、A13 Bionic、A14 Bionic、A15 Bionic、A16 Bionic；之后写A17 Pro、A18 Pro、A19 Pro、A20 Pro。卡标题和套装内部行完全一致。天玑1000不写成1000+，骁龙855/888不写成加强版。麒麟990/9050按用户家族名；具体版本资料边界另注。

两年世代是供货方案窗口，不强行伪造现实首发年份。T760本轮可核对实际终端应用，但原始发布档案不足，第三代归档保留为首测设计。8EE6、O3及9050无后缀版本的不确定性明列。厂标是虚构供应商，不代表现实芯片制造商；卡面仅图案与厂名。

## 03 特色落在产品取舍上
A11 Bionic让低规格影像模组取得影像用途；A12/13以影像或系统研发发挥计算摄影；A14/16分别处理芯片与显示负载；A15需要监看显示与系统研发；A17/19面向不同技术配套的图形路线；A18以高价专业视频取胜；A20维持受集成占位限制的高端创作组合。

骁龙855提供影像兼容入口，888保留高负载与三路影像特色；天玑1000突出集成低耗，9200突出光追与平台研发。猎户座9820强调场景处理；谷歌仍以系统AI和计算摄影配套为主。展锐采用真实的低规格、低成本与用途入口，而不是冒充同代最高性能。

能力条件只读卡上印刷参数、所选价格和已经部署的技术。没有新的资源、历史记录或奖励券；“取得特征”“市场许可”“竞争力加分”分别解释，不能互相代替。

## 04 数值只改必要位置
七个更换平台的芯片行有规格／负载／制造费变化，C112入库改普通8／伙伴2；其余芯片行优先保留6.8。不同定位不追求相同通用规格；T760加入后第三代稳定芯片规格差可为4，不再机械执行旧测试的差不超过3。

所有套装的屏幕、影像和机身行保持原数据。研发41张、合同30张、设施18张、方案24张、参考30张、需求12张的机械字段不变；6.8逐卡费用／工期、伙伴优惠、T21、联合授权与发布扩产继续使用。新价格、专长仍是测试参数，不是实测瓦数、跑分或现实采购报价。

## 05 实测要观察什么
先观察低成本芯片在18/28价能否成立；哪些专长真正改变技术选择，而不是默认触发；同代稳定反复供应、定制单批冲击与一次扩产是否都有价值。尤其不能用仅找到一套合法样机代替完整的取得路径和多人平衡。

验证分为数据守恒、能力条件正反例、实际配套见证、授权与扩产回归、文件渲染。各项检查记录实际范围，不声称已完成多人对局、真实硬件统一横测或打印机套准。本次不推送GitHub、不改原6.8快照。
