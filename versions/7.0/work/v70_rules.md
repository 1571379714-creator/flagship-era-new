# 旗舰元年7.0 完整规则书

双行排程与世代竞逐 · 2026年9月23日


## 01 一批手机，从组装到卖出

用统一牌市取得配件、研发、合同、设施与方案。把一组完整配置做成一批现货，先付款，再等待玩家共同推动的发布会。


### 1.1 一组配置是一批现货

普通产品位代表一批已经组装付款的手机。制造行动按强度可以依次组装1、2或3批；每批分别检查、付款和占用一个产品位。
同一批只投一个零售市场、一张合同或留库。未售原样跨场，可在以后自己的行动阶段取消；不设旧机年龄、自动降分或自动退市。
**发布扩产是例外：原产品初步获单后，每公司每场可追加一批同配置，另付成本、不占新产品位，且两批都必须当场获单。** 扩产见§13。


> 例子 / 关联规则：强度3制造最多组装三批，并非一张定制卡复制三次。每张定制实体仍只装一批；扩产才允许同组复用。


### 1.2 现金付成本，收入与科技相向走

现金用于入库、制造、研发、授权与经营，不是收入轨。收入是成交等商业成果，科技是本人研发与验证成果。
**收入0—130、科技0—46，两种标记沿同一版图反向前进。科技0→8每步对齐2格收入，8→46每步对齐3格收入。** 直接按科技刻度移动，不在游玩时换算倍数。
任意玩家自己的两个标记相遇或越过，即进入终局检查；先完成当前回合全部结算，再让每人各行动一次，随后最终发布。最终比较相遇线两侧的净距离，详见§15。
授权款只是现金转账，不自动增加任何人的收入或科技。


> 例子 / 关联规则：科技22标记对齐收入72。收入50时还差22格；收入72时相遇。不是收入或科技各到一个独立数值就结束。


### 1.3 玩家用真实成果决定什么时候发布

没有固定轮数、销售季或每代固定发布次数。发布轨终点为2人8、3人12、4人16。
制造和科研成果可以当场选择预告；已有至少两批合法现货的玩家也可用运营行动付费宣发。具体强度和额度在六张行动牌与§3写明。
轨到终点后，完成该次行动及阵列整理，立即共同发布，没有额外响应回合。空桌的普通推进最多到终点前1；最终发布可为空。


> 例子 / 关联规则：只有拿钱、拿牌或签空合同，不会让发布轨前进。两次实际发布之间称为准备期，合同与每期能力跟随实际发布。

## 03 六行动双行排程

六张牌一直可选。一次回合只选一张，按当前强度执行，然后整理本行并决定是否交换两行的1。


### 3.1 先做行动，再整理位置

选一张行动，以使用前所在列的1/2/3为本次强度。完成其一整行效果后，拿出该牌；本行其他两张保持原先相对顺序，放到2、3，再将用牌放回本行1。
**随后可交换上、下两行的强度1各一张，也可不换。** 每回合只选择一次，不可先换再选行动。另一行不自动升强度。
发布不重置阵列，额外取牌、安装和发布扩产不算第二个行动，也不整理第二次。


> 例子 / 摆法：下行D/E/F，使用E后成为E/D/F。若再与上行1的A交换，下行成为A/D/F，E移到上行1。使用1时本行顺序不变，仍可选择跨行交换。


### 3.2 六张牌的强度表

| 行动 | 强度1／2／3的主要效果 |
| --- | --- |
| 调研 | 取至多2／3／4张，牌市和盲抽可混选。 |
| 供应 | 安装1／1／至多2张不同类别稳定件；强度2或3完成安装后可盲抽1张。 |
| 研发 | 给1个项目推进1／2／4格，可立项，不能转移剩余进度。 |
| 制造 | 逐批组装至多1／2／3批，分别付款和占位。 |
| 合作 | 处理1项企业事项；强度2或3成功后可盲抽1／2张。 |
| 运营 | 拿6／12／18现金；或符合条件时付3现金宣发，推进1／1／2格。 |
所有强度都保留基本功能。现金仍照卡支付，强度不提高手机质量。


> 例子 / 摆法：连续用制造可以一直以1强度造一批；要恢复较高强度，需要使用同一行其他牌，或把它换到另一条循环。没有任何牌被禁用。


### 3.3 调研、供应与合作不互相冒充

调研只取得牌，不能顺便安装、签约或研究。选牌全部结束后一次补空位。
供应从手牌依次安装；同一次强度3供应至多两种不同部件，每张单独付款。强度2/3必须真的装好至少1张，才可附抽1张；附抽在全部安装结束后，不能继续装刚抽到的牌。
合作在签1合同、建1设施、建立/切换核心中选一项，付钱并查前置；同次不能做第二项。强度2/3的附抽在事项完成后进行，不立刻打出。


> 例子 / 摆法：不能空选供应领取附抽；不能空选合作拿牌。强度高也不免入库费、建设费和核心费。关系按每项业务完成后更新，后续安装可享新关系。


### 3.4 研发只推进一个项目

一次研发选择手牌中的一个新项目立项，或选择一个已有项目推进/复核。本次强度给出的1/2/4格已经包含立项，不额外再送1格。
本次最多处理且完成一个项目。进度到所选模式工期即停，剩余额度不转给别的项目。缺证明停在待验证，以后再选研发复核。实验室依法加速，也只作用于该项目。
也可放弃全部进度，改为独立验证：付12现金、出示基础竞争力至少12且至少2特征的真实现货，每公司每当前世代一次得1科技。任何强度可选，详见§9。


> 例子 / 摆法：联合工期3，用强度3立项并给4格，只到3并检查证据；不会又免费立第二项。自主工期7，可用4＋2＋1完成。


### 3.5 成果预告：行动完成后才决定

强度2制造：本次真正组装且在行动结束时仍存在至少1批，可推进1格。强度3制造：按本次实际保留的新批数推进，最多2格。强度1不预告。
强度2/3研发行动完成所选本人项目，可推进1格；独立验证、只立项未完成、奖励中完成研究、签约、取牌、入库和取消都不产生预告。
可推较少或放弃，不能留到以后。制造附加额度与实验室不会改变本次原强度或预告上限；扩产不预告。


> 例子 / 摆法：强度3做了3批可推0、1或2格；只做1批最多推1。强度1经U02做了2批，仍不能预告。取消本次新货不能同时保留它的预告。


### 3.6 有货才能付费宣发

运营的现金与宣发二选一。选择宣发时，行动开始前本人须有至少2批合法、已经付款且尚未结束占用的现货；付3现金，按强度1/2/3可推进1/1/2格。宣发不再拿运营现金，也不补产。
全桌没有合法现货时，普通推进最多到终点前1格；不能凭科研反复空发布。以后有货也不会自动补那一格，仍须有人取得合法推进机会。
进度到终点后不再取消产品或换配置；完成阵列整理立即发布。最终发布按终局规则无条件举行。


> 例子 / 摆法：四个产品位全满仍可运营宣发，不必取消重造。只囤一批、空运营或无产品科研不能刷空发布。有人有货后主动抢开是正常竞争。


### 3.7 一个回合如何结束

本人回合开始，恢复本人回合限次；可以做牌面明确允许的行动前事项。免费取消可在选行动前、或制造的批次之间进行，不会取得第二次行动。
选择并完成一次六行动及其合法附加效果 → 决定成果预告 → 整理本行、可交换两个1 → 手牌弃至上限 → 发布到顶则完整发布 → 开放本回合达到的新世代 → 检查相遇终局 → 下一人。
牌面额外拿牌、安装、研究进度都不改变阵列次数。新设施不回溯本次行动开始前的触发；共同发布中只执行明文允许的扩产与奖励窗口。


> 例子 / 摆法：若一次行动既科技到门槛又推满发布，先按当前世代发布，再开放新代、标定下一场参考代。不要中途换参考机或用新代配件补货。


## 04 一个主牌堆，五代卡都能拿




### 4.1 先选完，再补一次

调研行动强度1/2/3取得至多2/3/4张主牌；每张选当前牌市或主堆顶盲抽，可混选。所有牌先入手并占手牌，不另收取得现金。
选择期间空位留空，不左移、不补新牌供本次再挑；选完后统一补空位。附加连续取牌奖励也按整个奖励结束补一次。
主堆空时仅洗主弃牌；库内牌、现货、在研、已完成、合同归档和移出区不能混回。无牌就只取实际有的。


> 例子 / 关联规则：同次选牌不能拿走2号、补出一张，再把新2号拿走。未来卡照样会抽到，但不能提前用于产品。


### 4.2 领先科技开放新代，不另设产业轨

全桌任意一人科技第一次达到4／9／15／22，分别开放II／III／IV／V代；在该回合全部行动与可能的发布结束后生效。多门槛同回合到达，直接开放最高相应世代。
所有五代已在主牌堆中；换代只改变可用权限，不加牌、不刷新商店、不计发布场数、不统计公共产业贡献。配件与Q的世代不得高于当前供应代；研发、合同、设施按自身前置使用。
本准备期参考世代固定，中途供应换代不改变它。普通发布整理完并开放新代后，标定下一场参考代；具体参考机仍等下次锁定后抽。


> 例子 / 关联规则：每代约两场只是实测目标。领先科技可以提前换代，不要求全桌都贡献，也不等固定第二场。内容五代仍对应2017—2026的两年窗口。


## 05 供应商关系：用业务建立技术网络

五厂是虚构供货网络，不是玩家阵营，也不是芯片真实制造商。所有玩家都可与多厂合作。


### 5.1 看供货厂，不数颜色点数

每张非初始配件印一个供货厂，整张多项定制的所有部件都从该厂读取。初始通用件中立。现实芯片名称与供货厂是不同信息；红厂不代表高通，任何芯片都不凭品牌自动加关系。
每家公司对五厂各处于普通、伙伴或核心。普通客户可正常拿牌、安装、组装和签开放合同，不封锁未来发展。伙伴可按卡面伙伴价安装，并购买该厂公开技术授权；核心额外可以立项该厂联合研发。
关系不是六种产品特征，不参与性能/影像入场，不累积成科技点。


> 例子 / 摆法：A的蓝厂芯片是“这张供货方案来自蓝厂”，不是把真实芯片制造商改成蓝厂。


### 5.2 实际业务结束后，成为伙伴

发生以下任一行为，整项结算完成后，把相应厂从普通升为伙伴：①实际安装该厂非初始稳定件；②实际付费组装使用该厂定制的一批现货；③完整交付该厂订单或完成其验证合同。
一次组装有多家定制，可分别建立这些伙伴。已有伙伴/核心不再升级或领奖。拿牌、初始发放、临时样机、单纯签约、免费取消、回购、出口或服务合同自然到期均不触发。
费用与前置读取行为开始前的关系；不能先享受伙伴价，后用本次业务来补资格。未来稳定合法入库也可建立伙伴，但仍没有提前使用权。
扩产只是已存在产品组加量，不重新发送组装/建立伙伴事件。


> 例子 / 摆法：某卡印普通13／伙伴3：首次安装仍付13，完成后才成为伙伴。以后另一张同厂卡按它自己的伙伴价付款；不退第一次的10点差价。


### 5.3 核心合作开放联合研发

已经是目标厂伙伴，可用合作行动选择建立/切换核心并付12现金；全公司同时最多一家，各公司可选同厂。不占合同槽、不直接得分、不提供五套固定被动技能。
首次核心可并入首次联合立项：尚未选过核心时，可在研发行动中同付12核心费和联合费，确立核心并给项目本次完整1/2/4进度。先确认全部伙伴、前置、部件、槽位和现金再执行。
以后切换须合作行动并付12；任何未结束联合项目存在时不能切换，须先完成或放弃。旧公开成果与作者署名不撤回，不迁厂。


> 例子 / 关联规则：强度3首次联合T01：付12＋9，项目至多获得4格、到工期2即停。首次合并不等于先免费合作再额外研发一次。


### 5.4 所有具体价格都印在相应卡上

稳定件按当时关系选卡面普通入库价或本厂伙伴价，核心同伙伴；其他明确减免从所选价继续扣到0，不返还多余折扣。价格差逐卡不同。
研发卡直接印自主/联合各自现金与工期、完成科技、每批授权费和关联部件。两种模式不按固定倍数互推。
六行动牌印各强度额度；个人版图印核心12现金、独立验证12现金和宣发3现金等共通数字。卡面不重复印“取得0”，初始另写开局免费。


> 例子 / 关联规则：卡印普通13/伙伴3，不能先按3付款再减一次10差额。授权现金给作者，制造现金给银行，两笔分别支付。


## 06 稳定库四栏：实体不动，产品用代替卡




### 6.1 取得与入库是两件事

芯片、屏幕、影像、机身各一个稳定栏，初始也占栏，没有隐藏备用库。
供应行动按强度从手牌安装稳定件，付普通/伙伴入库费，替换同类原卡。被换下的非初始卡进主弃牌，初始卡移出本局；不退原入库费。定制不能装进库。
未来世代可以付费装入，却暂时不能用于组装或样机；有产品引用的栏位不能撤下、替换或挪动。奖励签装等例外也不突破锁定。


> 例子 / 关联规则：强度3可安装两类，但不是四栏全换。第一次安装建立伙伴后，第二项同厂安装可使用已生效的伙伴价，仍需不同类别。


### 6.2 每类代替卡读取同一库栏

产品用“稳定部件·种类”代替卡，读取本人同类库栏的实体规格、功耗/供电、制造费、供货厂与能力。稳定实体始终留库；初始中立件不冒充任何厂。
不同产品可同时引用同一栏，每批分别付制造费。代替卡不是独立配件实体，不多给厂标或关系，不占手牌，不可卖弃。多项定制整张同批，不与代替卡重叠部件。
**只要仍有产品引用，该栏锁定。** 未售产品跨场不复位；无须另记锁定次数。
扩产组原批与追加批共用既有代替卡，库中实体不移动；不因＋1复制厂标或解锁库栏。


> 例子 / 摆法：A的库内蓝厂屏幕可供A①和A③；两批分别是蓝厂屏幕产品，但公司不会凭代替卡新增两次关系。


### 6.3 何时解除引用

取消产品时，收回该产品的代替卡；其他产品引用不受影响。
发布时先保存全部产品，确认销售、挑战、研发和处置所需的证据；**证据与相关奖励核验结束后**，才统一释放已成交、渠道回购、H29出口产品。不可卖掉一批就立刻换卡改变其他批次。
供货签装发生在上述释放之后，属于本场明确的奖励安装窗口。若仍有未售／留库产品引用，该栏仍锁定，不能利用奖励绕过。
未售或留库产品跨场保留原配置，不自动解锁。
被扩产挤掉的原批未成交，仍保留引用。扩产组两批都成交，也只清理一次实际配置和指派。


> 例子 / 摆法：两批都引用屏幕，一批售出、一批留库。整理后屏幕仍不能换；供货签装也不能把留下的一批手机暗中升级。


## 07 一次组装，直接做出一批




### 7.1 按制造强度，逐批配齐付款

一次制造行动强度1/2/3，依次组装至多1/2/3批。每批选择空位，恰好配齐芯片、屏幕、影像和机身，来源为库内稳定代替卡或手中定制。整张定制必须同批全用、不拆不重叠。
每批可加至多1张Q，并指派自有或已合法购买的联合技术。先查世代、供电、折叠、兼容、Q、技术位、同公司技术占用、伙伴与联合适配，再付制造款和全部授权款，放使用片。
逐批完成后才能开始下一批；同张定制或部署技术不能重复占用。剩余额度可放弃。合法完成该批后建立其定制厂伙伴，新关系不能倒过来满足刚完成这批的授权。


> 例子 / 关联规则：一张稳定芯片可供三批；一张定制芯片只能装一批。组装不是免费，每批有自己的费用和产品位。


### 7.2 功耗与特征直接看卡

芯片、屏幕、影像各自有效功耗＝印刷功耗＋锁定调校增量−本机合法减免，各项最低0。三项相加不得超过机身有效供电；供电余量＝有效供电−有效总功耗。
只用屏幕与机身判断直板／折叠形态：折叠屏与折叠机身必须配套。芯片与影像不承担直板限制，可以用于任一合法机身形态。高级影像按本卡“芯片规格至少…”检查；具有明确兼容能力的芯片或已部署T26／T38可豁免该项，不跳过世代、供电或折叠配套。
基础竞争力＝四项印刷规格＋明确的通用修正，最低0。市场专长、需求偏好及价格修正不计入基础。卡面“屏幕印刷规格≥7”等条件只读印刷字段，不拿临时市场分来满足。
多个不同来源合法加分可以相加；同一多项定制的整卡特性每批只执行一次。调校最多一种，组装时选定；取消重组才能改。
本场扩产继承初步分单前已经算好的竞争力及资格；不靠新增批数再触发配套加成，也不重算原产品能力。


> 例子 / 摆法：“影像竞争力＋4”不会提高影像部件的印刷规格。若一张卡的专长未满足条件，仍可使用它的基础规格，不必整批判失败。 芯片卡上的“取得特征”只改产品资格，不抬高部件规格；“可进入某市场”也不自动取得该市场偏好或安全资格。


### 7.3 六种特征与入场资格

| 特征 | 通常来源 |
| --- | --- |
| 性能 | 芯片规格≥6 |
| 影像 | 影像规格≥6 |
| 轻薄 | 机身有轻薄标识 |
| 续航 | 有效供电余量≥4 |
| 折叠 | 折叠屏＋折叠机身配套 |
| 生态 | 芯片生态标识，或卡面明确授予 |
大众消费接受所有合法产品；电竞通常需性能，摄影需影像，商务需续航／生态／折叠之一。卡牌可以放宽。安全与耐候仅为合同资格。
卡面标识不一定自动成为整机特征：低规格影像上的“影像”字样不替代规格≥6；牌面明说取得才算。上述条件也印在部件与产品速查卡。


> 例子 / 摆法：同一产品可能合格于三个市场，但只有一批货，锁定时仍只能选择其中一处。


### 7.4 制造款与授权款分开结清

制造款给银行：四部件印刷制造费＋有效组装费＋Q方案费−明确总减免，最低6。通用组装费8，只减组装费先到0；多项定制各行相加。
外部授权款逐项给署名作者，另加在制造款之外，不参与制造最低值或通用减免。开始每批前现金须足够两者总和；原作者自用不向自己付款。
普通制造的第一批优惠按行动限一次，不因接着做第二批重置。扩产按发布开始的冻结配置及持续减免重算，不回忆历史付款，也不享受正常制造/首次/取消优惠。


> 例子 / 关联规则：强度3有三批机会，但U11只减第一批组装费；扩产另付制造与授权，不再支付入库费，不用本场销售款垫付。


### 7.5 集成占位与T21：不增加产品格

产品通常有2个技术位。先加总部件印刷集成占位；除T21外，每张部署技术再占1位，合计不得超过2。集成占位不是研发，不给科技或本人科研资格。

**T21高密度封装是例外**：只有原始部件集成合计至少1时才能部署；T21自身占0位，并把集成合计减1、最低0。总上限仍为2，不叠加、不扩大成3或4位。无集成产品不能挂T21来补挑战资格。

T21仍要真实完成或合法付费授权，并用原有产品指派片表示；最多T21＋两项其他部署，现有每产品3枚片足够。不另放减位片。联合适配、世代与技术使用限制照查。

扩产沿用已经合法的配置，不把两批位数相加，也不再次应用T21抵消。临时样机同样检查，不能用尚未完成的T21证明自己。


> 例子 / 摆法：集成1＋T21＋T07＋T26：集成变0，T21占0，另两项占2，合法。集成2＋T21只剩1个位置可部署其他技术。无集成＋T21不合法。


### 7.6 规格有代际梯度，不是现实跑分

芯片规格是压缩的产品能力档位；负载不是瓦数，制造费不是现实报价。同系列代际以8 Gen 2＝12、8 Gen 3＝14、8 Elite＝17作锚点；第五代继续有增长空间。
配件值直接读卡，不按世代再加分或自动折价。芯片与影像不印无意义的直板属性；屏幕、机身仍分直板与折叠。
48售价通常须基础竞争力≥28，并满足芯片规格≥12或影像规格≥8至少一项；卡牌明确许可可替代。高价仍要符合需求预算。性能通常芯片≥6，影像通常影像≥6，保持入门市场可达性。
每张卡的适配、样机、费用与专长都按自身文字；同一规格不表示两款真实芯片完全等速。


> 例子 / 关联规则：新一代同类芯片主要性能更强，旧平台仍可更便宜、适合既有供应商。强芯片不让研发、授权或扩产免费。最新两款的来源与未统一实测边界见芯片资料说明。


## 08 取消、改款与跨场等待




### 8.1 取消回件，不退投入

在自己正常行动阶段，选行动之前或制造批次之间，可免费取消尚未成交产品。制造／授权现金、已用行动与已领奖科研不退。
定制与Q整张回手，代替卡和使用指派收回，产品位清空；稳定实体留库。其他产品仍引用就仍锁定。取消不复位回合、准备期、验证或扩产限次。
发布开始或预告已把轨推至终点后不能取消、换价、换库、改配置。取消不是行动，不移动阵列。


> 例子 / 关联规则：刚造好又取消，不产生可保留的制造预告。额外组件只有回到手里的实际那张卡，不生成第二套。


### 8.2 改款就是取消后重新制造

基础规则没有免费修改已经付款现货的步骤。取消原批，再在制造行动额度内用调整后的配置重组，重新检查并付完整费用。
T31/U14只奖励制造行动内取消后紧接同位的那一次组装；在选行动前取消、之后隔着其他事项，不能追溯其优惠。每次制造行动各最多一次。
普通复制另一批占另一空位，定制与技术不得重复使用；只有发布扩产可在同组追加一批。


> 例子 / 关联规则：修正配置不是修改旧数值。未售等下场不重付；主动改款才取消再付款。


### 8.3 未售原样留下，成交则结束

未售/留库完整配置原样跨场，不减分、不回手、不付款，不记录代龄，仍占产品位和全部引用。下场可重选价格与唯一去向；公开过的技术指派不再反扣隐藏。
零售/合同成交在全场证据及奖励检查后清空：定制/Q移出，Q21按自身真实成交例外；代替卡与使用指派片收回。永久署名不收，不为下一批保留旧授权。
渠道回购、H29出口不算真实成交，不加收入、不挑战、不触发Q21等成交能力，也不建立成交型供应商关系；按消耗结束占用，同批不重复处置。
临时订单被扩产挤掉，按未售原批处理。成功扩产只有当场成交两批的结果，不能故意留库、取消扩产或制造第二套可回手实体。


> 例子 / 摆法：联合技术的作者拿过授权费，产品没卖掉也不用退；批次还在，买方下场也无需再次付费。


## 09 研发与证据：不记录产品历史




### 9.1 选一个项目与一种模式，投入整次进度

研发行动只选择一个新项目立项或一个在研项目推进。立项从手牌支付卡面所选模式费用，占在研槽；强度1/2/3给1/2/4进度，已包含立项。
自主无厂商关系要求，完成后本人独占。联合须核心与已开放本厂关联部件；立项时展示可用部件，完成时仍须原证据及合法本厂样机。首次核心可按§5.3合并。
到本模式工期且证据满足，领取印刷科技一次。缺证据停为待验证；以后一次研发选择它复核，不能同时研究别项。费用减免最低6，核心款另付。
可在自己行动前免费放弃未完项目，牌进主弃、钱不退；不能中途改模式、补差买独占或撤回公开成果。


> 例子 / 关联规则：联合9现金/3进度，自主12/6，直接读卡而不是乘2。已有进度2，用强度3只补到3，不把剩下3格转给别的科研。


### 9.2 用现货或临时样机作证

完成项目的证明可用现存合法产品，也可临时拼样机。临时样机用本人库内已开放稳定、手中未占用定制和本人未占用完成技术，不付款生产、不产库存，展示后归原位。
样机仍检查完整四类、世代、形态、供电、兼容、集成/部署位及联合适配。两样机须同时合法，定制/技术不得在本公司重复占用；稳定可共享。正在完成的研发不能证明自己。
**联合完成除原证据外，至少有一款证明样机使用合作厂的卡面关联部件。** 原证据为“无”也要提供这款样机。相关部件来自单项稳定或多项定制均可，后者厂标对其所有部件有效。
不能为临时样机免费借用他人的公共技术。本人已经制造、实际付过授权费且授权仍有效的完整产品可以作证；取消后不能把借用技术移到临时样机。独立验证只用真实现货。
原产品的扩产批不构成第二款独立样机；需要两款同时存在的样机，仍须两个原产品位或两套合法临时配置。


> 例子 / 摆法：蓝厂T09关联屏幕：要有合法蓝厂屏幕样机，芯片、影像和机身不必蓝厂。T09自己的减功耗不能拿来使这台证明机合法。


### 9.3 工艺与部署的区别

完成自主研发，原卡进入本人公开完成区；工艺立即作用于公司，部署技术在后续组装中分配。完成联合研发，原卡进入合作厂公共技术区，放永久作者圆片；同项科技仅由该作者领取一次。
统计本人完成项目与领域时，计算私人完成区和公共区本人署名卡；不计算外部授权或指派片。已完成成果不能退回在研、自主转公开、公开转独占，不能移动合作厂。
联合作者也须满足关联部件同厂，并放使用指派片才能给自己的产品生效；只是署名不会覆盖全公司。其他公司的使用不占作者那一格。
工艺不占技术位、不可联合授权；本版35张部署技术可联合。新研究不自动强化已经制造的产品，需取消重组；发布中完成不重算本场结果。
同产品扩产只扩大本场交付数量；不重复领取研究完成科技、不改变署名，也不开放新的技术使用目标。


> 例子 / 摆法：公共T09上有作者A，使用B③、D①。只有A增加完成项目数；B、D只是各有一批使用权。


### 9.4 独立验证是研发的替代选项

任何强度研发都可改为独立验证，放弃该次常规进度：付12现金，公开基础≥12且至少2种特征的真实合法现货，得1科技。临时样机不能代替。
每公司每当前供应世代最多一次，在本公司I—V格放已用片；不能补领过去世代，也不因取消、改号、授权、换核心或发布复位。
T32降低产品门槛；U12/Q22降低现金；T39在验证后给一个已有项目1格额外进度，不立项、不叠实验室，也不产生预告。
运营已统一承担补现金，删除独立“技术服务”行动入口。


> 例子 / 关联规则：科技22开放第五代后，可以做第五代验证；还没有进入第五代就不能预领。验证是整次研发行动，不能再使用该强度的4格常规进度。


### 9.5 一枚进度片只看当前模式终点

项目卡印两种费用与工期；在研时放联合模式片或按自主处理，用一枚进度片沿0—8条到所选工期。
各卡进度不同，整体约两倍只是设计参考。项目终点不因本次行动强度、实验室或奖励而改变；强度改变一次投入多少。
合法加速只作用于此次项目，超额不用。后续新项目需要另一次研发行动；发布奖励完成项目也不插入额外行动或预告。


> 例子 / 关联规则：T18联合工期5：强度3立项得4，之后强度1推进到5。自主工期8可两次强度3完成；时间取舍与现金取舍分开。


## 10 公开技术：署名与每批使用权

工艺只自主；可联合部署技术完成后公开。作者、供货厂和实际使用者是三种独立信息。


### 10.1 厂区、圆署名、长方指派

联合完成后，原T卡放在合作厂公共技术区；圆形署名片放卡的作者栏，永久标出A/B/C/D。该厂由卡所在区域表示，不额外复制T卡。
T卡下沿另有A/B/C/D四个使用位置。准备期把公司的长方指派片反扣在本公司格，背面只写公司，不显示产品号；揭晓时翻成公司字母+产品①—④。
原作者使用也放自己的指派片。没有片就没有部署；圆片只证明科研所有权，不占产品技术位。未售公开产品的片保持正面。


> 例子 / 摆法：蓝厂T09：圆A＝作者A。长方B③＝B③正在使用。B取消③只收B片，不能动A圆片。


### 10.2 普通组装授权与扩产例外

本人至少是该公共技术所在厂的伙伴，本批卡面关联部件来自该厂，且满足技术实际条件，才可在组装中使用。多项定制覆盖关联部件时读整张厂标。

**先把本场结果算完，再处理奖励安装和建设。** 普通成果、挑战资格、研发证据与回购对象都在配置尚完整时检查。
渠道回购只处置本公司的另一批合格未售零售货，不加收入，不触发成交奖励。先标定回购对象，H29随后只能选择仍未处置的另一批；同一产品不能两次收钱。
完成这些核验和即时奖励后，全桌统一收回已售／回购／出口配置。随后按触发者下一位起，结清已选供货签装或建设支持。可用本场已经到账的现金，不能借未来收入。
签装仍查手牌、实际入库费与引用锁定；建设仍查手牌、现金、空间和前置。两者都不是供应或合作行动，不触发T36增加供应安装上限，也不触发这两项行动的附带抽牌。
选奖励时可先检查对象是否可行；一旦选择不能因为随后不满足而改奖。无法执行就放弃，此次机会不带到下一回合。
被扩产挤掉的合法原批可以成为回购/出口对象；复制批本身不可回购/出口。签装必须等该栏所有已结束引用都清理完，未售引用仍锁定。


> 例子 / 摆法：一批售出、最后一个芯片引用释放，才可用供货签装升级。若另一批留库仍锁芯片，就改装可换的屏幕，或选收入等奖励。


## 14 发布完整顺序与整理




### 14.1 完整发布：先锁定、再扩产、最后领奖

①锁价/去向，揭晓配置与指派，从本场参考代完整6张现抽1张。
②核验原有现货的合同整单交付，暂不领款、退押、清卡。
③冻结原产品竞争力与扩产费用；依大众→电竞→摄影→商务，临时分单、按序询问扩产、试排付款、确认本市场最终结果。
④冻结全部成交、挑战、科研成果、授权和回购证据。
⑤从触发者下一位起，领取合同、零售和普通成果，再结清现金、拿牌、工程、回购。
⑥处理出口、Q21与证据；统一清理已售/处置产品及使用指派、＋1片，作者片永久不动。
⑦结清签装/建设，处理期限、维护、每期复位及牌市/需求；开放本回合科技达到的新代、标定下场参考代、发布归0，最后检查双轨终局。


> 例子 / 关联规则：所有四市场扩产完成前，不领任何销售、合同、押金或挑战款。实际收到的别人扩产授权款可以用于之后的自己扩产。阵列在进发布前已整理，不因发布再重置。


### 14.2 每份钱只领一次

合同按原有整单结算与退押，扩产不可补单；零售按每个最终成交批次结算。普通组收1批，带＋1组收2批，放已收款片防重复。
T41每场只对所选生态产品组的原批价牌收入转1科技；扩产批收入照拿，Q15等独立奖励不受转换。H28前2批上限含扩产；U17只看最终市场覆盖，Q24只加1次，Q21只归还实际一张Q。
制造款给银行，外部授权逐批给原作者；授权款不是收入/科技。扩产曾支付第二批授权，销售结算时不再付第三次。新授权触发U18仍共用准备期限次。
回购/出口不叠销售、收入、挑战、Q21或新伙伴。签装和建设在统一释放后使用已经到账现金，不能借未来款。


> 例子 / 摆法：A收到B的第二批4授权现金，不增加收入。B扩产两批卖38，基本拿76现金与6收入；没有第三次授权收费。


### 14.3 一次刷新，其他只移标记

本场已经在⑥清掉的产品不再次清理。供货签装／建设支持在⑦执行完就收回挑战选择片；没有未用券保留。
普通发布末，已完成合同归档；未完成合同减1期限，到0没收押金。H29先于到期。维护只检查发布开始已有设施；建设支持的新设施本场不维护，也不补领收益。复位每期能力，不复位公司世代验证。
主牌市弃最左2张、其余左移、补8，一次完成。N进需求弃牌并抽新N；堆空才洗同类弃牌。V归还该代六张候选。处理待开的供应世代，标定下场参考代，发布归0；全桌各弃至手牌上限。
换代不另刷新，不维护分类商店。
普通发布整理后把每家公司扩产状态恢复可用。临时＋片不能跨场保留，也不因进入第二市场就复位。


> 例子 / 摆法：新设施从接下来的行动使用。已售／回购／出口三种片都解除占用，只有真实成交的Q21能回手。


## 15 最后阶段、速查与测试边界




### 15.1 标记相遇后，每人再行动一次

任意时点本人两标记相遇或越过，记录终局将触发；先完成当前回合所有效果及可能的普通发布。触发者是当前行动者，即使达标的是收授权或奖励的另一人。
之后从当前行动者下一位起，每人再有一个完整回合，当前行动者最后；每回合仍只选一张六行动牌并正常整理阵列。
最后阶段推满发布不再中途开普通发布；最后一人结束后，按已标定参考世代锁定、现抽并举行最终发布。没有第五代硬锁，也不因当前世代发布不足两次而延后。


> 例子 / 关联规则：本回合研发先让科技跨线，仍要完整处理它的效果、排程和应发生的发布；不是当场跳过其他玩家的最后行动。


### 15.2 最终计分：读取两标记之间的距离

最终发布照常合同交付、零售扩产、挑战、工程、回购、签装与建设；然后终止未完合同并没收押金。不抽下一场需求，不付下期维护，不改变阵列。
以科技标记横向对齐的收入格为相遇线：收入已越过，超过几格得几分；还没到，差几格记负几分。两轨覆盖整个130格跨度。最高分获胜；同分比较剩余现金，仍同并列。
超收入130后用数字筹码记录超出格数；超科技46后，每额外1科技继续跨近3收入格，单独放科技超出筹码。不把它绕回0重新用前8步比例。没有秘密终局目标。


> 例子 / 关联规则：科技22对齐收入72：收入80得8分，收入65得−7分。科技46对齐收入0；科技47相遇线越过收入0三格，收入2得5分。这只是读轨说明，不是固定倍数胜利公式。


### 15.3 首测参数与验证边界

本版从实际6.9迁移：六卡双行阵列、无通用工作点；制造/科研成果预告及有货宣发；科技领先4/9/15/22换代；收入130/科技46反向相遇；芯片12/14/17锚点并重标门槛、参考与需求。
315种内容牌、50唯一芯片、初始件、四栏稳定库、单合同槽、公开授权与每公司每场一次扩产继续保留。
每代约2场、第五代约2场为调参目标，不是固定流程或平衡结论。测试模型与实测分开，纸面节奏预算不冒充完整多人对局。具体覆盖与尚未达到的目标见验证记录。


> 例子 / 关联规则：连续运营但不造货不会推进发布；有货付费催开仍是正常竞争。极端研发可更快换代，极端不研发会更慢，规则不强制扳回两场。
