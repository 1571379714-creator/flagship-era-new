# 旗舰元年 4.8 → 5.0 修改与校验说明

5.0 五厂协同测试版 · 2026年9月20日

## 一、交付与继承边界

本版从实际4.8交付数据继续修改，不从4.4重建。4.8原始JSON、正文和版图保存在source；旧文件未覆盖，未直接改写用户本地C盘。

用户确认的改动：五厂为所有玩家都能积累的卡牌厂系；扩大现金与产品参数；增加有代价的科技路径；科技轨恢复0—36，0至8每步对应2收入格，8至36每步对应3收入格；以同一玩家的双轨标记相遇或越过触发最后一轮。数值、卡牌分配和新增具体效果属于本轮设计，不是原文件原有规则。

完整规则可独立阅读，不需翻旧版补丁。图鉴收录302种内容牌，按份数共374张，含原280种352张与新增22种22张。五种双面行动、每人九张定价牌和标记不计入内容牌。

## 二、五厂标签落实

红厂三角、黄厂六角、蓝厂菱形、绿厂三叶、黑厂圆环。颜色、形状、文字同时辨识，不映射实际品牌。厂家与性能、影像、轻薄、续航、折叠、生态六类别独立，不合成十一种标签。

公司厂标只统计已上市企划和已打出的科技/企业。产品厂系只统计已上市企划。R项目和O目标上的厂家是需求对象，不提供厂标。配件与个人版图不提供厂标；真实芯片型号不绑定手机厂。每张提供厂标的公司牌只提供1个。

四张起始企划P01—P04无厂标，仍保留原类别和市场；无厂标不是第六厂，也不是通配。所有玩家均可从后续牌流进入任一厂系。

## 五、多来源科技与36格双轨

41张科技分为13张0科技的应用技术与28张提供1—3科技的成果技术，印刷科技总和36。分类只是打出收益，不分牌堆；部分成果卡要求此前1或2张科技，新厂系科技使用厂家前置。全卡科技门槛重新印制，不沿用4.8的压缩换算。

27张企划有条件科技奖励，P24、P48、P71、P80、P86、P92提供2点，其余提供1点。P24与P64更侧重实际技术条件，而不是仅凭名次；P76引入不同厂系的新机协同。基础J与主牌R提供项目型成果，T39/T41提供建立后再发布合格新机才能取得的额外科技。空发布、旧机与仅拥有厂标均不会自动触发这些引擎。

基础研究取消整局一次：普通研发S至少4、付24现金；升级研发S至少3、付18现金，均得1科技，每次占用整个研发行动、至多一次。不受科技卡/厂系减费，不是打出科技卡，也不提供标签。它保证不完全依赖卡序的入口，同时消耗真实现金和行动机会。

### 终局规则

> 当任意玩家的两个标记相遇或越过，完成当前回合的全部结算后，所有玩家各再进行一个回合，随后举行最终发布并计分。秘密终局目标只在最终计分时加入，不会提前触发游戏结束。

收入0—100，科技0—36；0→8八步各跨2收入格，8→36二十八步各跨3格。8→9明确属于长步。终局只要求观察同一玩家的两个标记，中央版图直接画对齐线；没有继续使用固定五倍科技判定。计分以科技格对应的收入对齐线为零分线，数收入领先或落后的格数，再加秘密目标。

科技3、7的行动升级与供应链2、4、6、8是不同节点。供应代归属与刷新框架保留4.8；未解锁件不提前入库，同回合发布与换代只维护一次。本场奖励带来的世代变化不追溯改变本场费用和配置。

### 36科技的可达性见证

程序逐回合验证了一条极端双人路径：玩家1收入始终5，不发布产品，起手可保留T01/T19并打出取得两个性能类别；J01第一档未被他人占据。通过实际融资、整备与合法行动卡轮转，基础研究到科技34，此时尚未相遇；预先把升级研发保留到S至少3且有18现金，再用合作完成J01取得科技35触发最后一轮。其他玩家行动后，玩家1在额外回合以研发再取得1科技达到36。

该路径实测程序共223个全桌回合，第221回合触发，最后两个额外回合正常执行。35次基础研究的全部费用与打牌费用、行动强度和资金不为负均检查。完整逐步状态保存在work/technology_36_trace.json。
