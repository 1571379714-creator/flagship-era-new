# 《旗舰元年》5.0 五厂协同测试版

本版从4.8继续更新。完整规则、全卡牌和线下展示文件均在outputs，原始底稿在source，可编辑数据与生成脚本在work。原4.8文件没有覆盖。

## 阅读文件

- `outputs/旗舰元年_5.0_完整规则书.pdf`：19页固定排版；同名docx可编辑。
- `outputs/旗舰元年_5.0_全卡牌图鉴.pdf`：59页，全部302种内容牌，对应374张实体牌；另有同名HTML。
- `outputs/旗舰元年_5.0_线下版图.html`：10个静态视图，只切换/打印；同名PDF为10页A3横版。
- `outputs/旗舰元年_5.0_实体定价与标记.pdf`：4页实体功能组件；同名HTML便于查看。
- `outputs/旗舰元年_5.0_修改与校验说明.md`：改动、卡组分布、科技新数值、实际测试范围与风险。

## 打印

规则书和图鉴建议A4。图鉴是卡面式参考排版，不是含统一卡背、出血、生产裁切线的量产稿。

定价组件第1—2页每人一套，A4原尺寸、长边翻转双面；第3页每人单面一份；第4页全桌单面一份，包含M01—M04各10枚项目标记。先试印一份核对套准。游玩不用纸笔。可用自有现金筹码、棋子、遮挡屏和行动卡配合。

线下版图按A3横版展示/打印；对实体卡放置面积要求较高时可放大。版图格是功能区域，牌可摆在旁边；不需要用电子程序执行玩法。

## 最新设计约束

五厂对所有玩家开放，起始P01—P04无厂标。厂标与六类别分开计数。科技0—36，前八步每步对应2收入格，其后每步对应3收入格；同一玩家两个标记相遇或越过触发最后一轮，不采用固定五倍科技判定。所有玩家各再一回合，随后最终发布与目标计分。

## 可编辑与重建

修改核心卡牌数据：`work/v50_data.json`。修改正文：`work/v50_rules.md`。

`revise_v50.py`从4.8底稿生成本次确定的5.0数据，`make_rules_v50.py`生成完整MD。二者会覆盖手改JSON/MD，只有需要重新生成初始5.0时才执行。日常手改后只运行build/boards/export。

本包不含字体文件。生成时需要Python3、python-docx、CairoSVG、BeautifulSoup4、PyMuPDF、Playwright，以及系统Chromium、LibreOffice和Noto Sans/Serif CJK SC。安装在不同系统时字体、打印引擎可能改变分页，以交付PDF为固定结果。

常规重建：

```text
python work/build_v50.py
python work/boards_and_aids_v50.py
python work/validate_v50.py
python work/build_all.py --render-only
```

或一条命令重建全部文件（保留当前JSON/MD，不重跑初始修订脚本）：

```text
python work/build_all.py
```

使用系统浏览器时可设置`CHROMIUM_PATH`；系统未自动找到LibreOffice时设置`LIBREOFFICE_PATH`。本包生成器不需要网络连接，但软件及中文字体需预先安装。

各验证程序是本测试版的定向检查，不是通用桌游引擎。修改卡组规模或布局后，检查中的预期数量/页数也需要相应维护。没有多人平衡认证，90—150分钟仍待实测。
