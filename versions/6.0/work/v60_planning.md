# 旗舰元年
## 6.0 设计规划与迁移说明
产品平台与开放市场 · 从5.3结构重构 · 2026年9月21日

## 01 这次的设计目标
把主要决策从“取得企划、满足图标条件、推进双轨”转成“买哪种供货、研发哪种平台、生产多少、如何投放有限订单”。保留收入与科技两条可选择的主线，不强迫研究型公司先完成大量销量，也不让商业型公司必须凑科技才能赢。

用户最后补充的两点是本版硬条件：共同发布由玩家推动，绝不固定全桌轮数结算；参考机从多种机型随机抽取，提前公开，强参考格的挑战奖更大，弱格少奖或无奖。这里的“发布周期”仅指两次真实发布之间，不是预定轮数。

## 02 架构取舍
| 5.3结构 | 6.0处理 | 解决的问题 |
| --- | --- | --- |
| 五行动卡1—5位轮转 | 每本人回合3工作点，自主分配 | 重心从行动卡冷却移到工程投入与经营排期 |
| 双轨交会，收入和科技相加 | 任一主线达门槛结束；取两主线较高成绩 | 允许两条主线各自成局，不用同一交会跑分结构 |
| 企划是造机许可，达线发印刷收入 | 直接用配件造机；Q方案可选，收入来自真实成交 | 不因没抽到某企划而不能造某类产品 |
| 稳定件每场免费回库、旧机只存一个数字 | 部件与部署持续占用型号；库存真实付费 | 不再让旧型号免费复制产能或原配件 |
| 每公司每市场只取一个代表 | 所有投放型号都能成交，批次有限 | 产生自家产品分流与跨市场配货 |
| 集图标占档、秘密终局目标 | 有工期的研发、有限期合同和设施投资 | 成长由工程证据与履约产生，不靠纯收集目录 |
| 无条件正常回款 | 删除；现金来自实际销售、合同与服务 | 不能只让别人开发布就自动得到经营资金 |

保留的是手机产业题材、部件组合、功耗和结构、五厂视觉资产、公开抢供货、秘密价格与共同发布。243种设计不是按旧315张左右倒推的额度，而是按本版所需内容汇总；5.x卡面不能混用。

## 03 两条主线为什么这样计分
本版选择“取高值”而不是“把收入科技两项都加分”。收入门槛60，科技门槛30，科技计企业成绩时乘2，仅用于统一两条路线的计分尺度。这不是旧的收入加固定科技倍数触发，也不是双轨相遇的隐藏公式。

收入路线需要足量、能赚钱且真正售出的库存。研发路线需要资金、工期与完成证据。跨线投资主要为了经营能力，而不是为了同时收两遍主线分。较小一项只作第一平分判据，现金仅作更后面的平分判据。

这是本轮的设计选择，不是用户给定的数值。门槛60/30、工作点3及研发产出仍须实测。如果科技路线明显更快，应先调整研发工期/费用/证据或挑战奖，而不是悄悄把计分改回相加。

纯研究公司的现金有技术服务与验证合同两条非销量入口；样机证据也不要求售出。因此“可选主线”不是嘴上说科技可行，实际必须先铺三市场才能研究。

## 04 共同发布是玩家争夺的时间资源
每个本人回合可用一个工作点预热推进1—3格，不能反复在同回合用全部工作点直接跳满。除预热外没有通用自动推进。有人备好了货，就有动力催开；有人需要项目最后一点进度，则会选择晚开。

到顶等当前玩家工作结束立刻发布，不给其他人补生产回合。新结构允许当前玩家先预热再用本回合余下工作，也明确这是他的已知时间优势；它不是发布揭晓以后再额外组装。

玩家收入60或科技30控制整局终点，发布轨控制中间交易窗口，供货世代控制可用资源，两者不能代替彼此。不要求每局必须进入V代，也不要求发布固定次数。

需要观察的风险：大家都能靠服务拿现金，是否会长时间不愿推进；持有强科技的玩家是否利用低销量环境直接结束。首测先记录预热者与动机，不加入每轮自动推进来掩盖问题。

## 05 参考机的随机性放在准备期，不放在结算时
每代有六种定位，一场只抽一张全桌共用参考机，四个市场参数写在一张卡上。不是给每个市场各加一个可行动机器人，也不是固定同代所有市场一样高。

例如II代电竞性能机：大众11、电竞18、摄影10、商务11。摄影弱项无奖；电竞18是2星。可以转市场避开强项，却拿不到强项的大额挑战奖。这避免了“击败这张竞品任意弱项，就领整张卡最高奖励”的错误激励。

奖励完全由被挑战那一格的数值分档：至多10无奖，11—16为1星，17—24为2星，25以上3星。每星可取2收入或1科技。每公司每场最多一次，且必须严格胜出并有真实零售成交。并列虽然真人先拿订单，也不拿挑战奖。

科技奖励另要求首发、已部署研发。这保证强技术可以通过真实产品验证得到成果，又不让同一旧机低价甩卖每场刷技术。参考机总量是每市场最多1订单，目的是给无人进入的市场一个有限竞争压力，不能当成真人互动已经足够的证据。

供货换代时不临时换参考机。否则研发玩家完成项目推动供货后，可能在同回合突然拔高对手，破坏已经可预判的发布筹备。新参考机只在实际发布后抽。

## 06 多样化卡牌如何融入核心循环
| 内容 | 决策作用 | 不再承担的任务 |
| --- | --- | --- |
| 稳定供货 | 可重复生产的部件资格、芯片平台配额与代差成本 | 不自动送一批库存 |
| 定制整合 | 用一张整合方案压缩选件，同时提供特殊接口 | 不只是用完丢掉的高数值牌 |
| 可选产品方案Q | 转变目标客户、价格许可、批量或验证方法 | 不作为每台手机的必需许可 |
| 研发T | 投入工期、出示证据、取得成果或工程权限 | 不全是付款即全公司加数字 |
| 合同H | 确定订单、临时保供、研究委托与渠道窗口 | 不永久收集颜色堆经营加成 |
| 设施U | 投资产线、实验室、仓储和组织空间 | 不给基本造机制造场馆拼图门槛 |
| 需求N与参考V | 公开本期环境和有差异的竞品 | 不在锁价后随机处罚玩家 |

几条联动不是通用关键词连锁，而是改变同一个经营过程：

T37共用芯片＋Q05双版本平台＋H16主板保供，会扩大同芯片供给，但两款产品仍争同一个配额和真实订单。U13仓储给你留旧库存的空间，却不会帮库存自动成交。H29清仓出口能回笼现金，却没有收入点。

U05影像实验室＋H22影像验证，降低该方向的工期压力并补研究资金；T26让中端平台安装高级影像，之后Q06允许用较低整机基础分尝试48售价。市场预算不够时，再好的组合也卖不出去。

T41允许把一批实际生态销售的全部收入换成1科技。它提供路线交叉，而不是现金、收入、科技全领。U17奖励实际三市场零售成交，参考机、合同和回收不凑数。

## 07 复杂度控制与保留的抽象
只记录芯片平台配额，不给四类零件分别做库存数量台账。批次库存归属于型号，不逐台追踪序列号。固定四个型号位、两个在研、两个合同和三个设施空间，设施能有条件放宽后面三项。

产品特征仍使用六个容易识别的词，但从真实部件与供电推导，不再统计公司累积了几张性能图标。五厂只表示当前合同伙伴，多厂合作合法，不恢复固定阵营。

保留一项通用基础竞争力，加入偏好、价格与年龄；没有恢复原版五维系数乘法与多档客流递推。每一批先生产、再成交，利润表现为真实现金收支，不在每次发布里再算“成本返还＋客流乘毛利”。

取牌区仍较多，这是多样化供应与商机的代价。未开放资源必须分包；牌面用取得成本、生产成本、工期、订单数量等独立字段，不能把同一个现金数字同时解释成所有费用。

## 09 首测安排与判定标准
先做2人对局，因为最容易看出同市场缺乏争夺或参考机过强。再做3/4人以观察发布结算时间。使用完整牌库，但不要预期一局看到全部卡。

记录每次发布的数量而不是只记最终名次：各型号生产批数、合同留量、四市场投放、实际零售成交、参考拿走订单、无人购买库存、价格选择与挑战收入/科技。还要记录每公司工作点用于生产、科研、服务、取牌和预热的比例。

重点问题：是否真的出现两个玩家争同一份订单；是否因参考机定位改变备货；降低价格是否能改变成交，而不是永远选最高价；研究路线是否能自行维持现金；共享平台是否迫使有意义的产品取舍；临时渠道合同是否具有可预测的使用窗口。

发现问题优先调整一个变量：订单量、参考容量、价格竞争修正、生产配额、工期或门槛。不要同时增加工作点、补钱、降低全部预算门槛和加分，以免无法判断根因。

程序验证只覆盖明确模型与构造性局面：订单守恒、库存不复用、同分、预算、参考奖励一次性、收入/科技选高、供货用量不靠退市复位等。没有完整隐藏信息策略代理、所有243卡交互穷举、实测胜率或真实时长结论。
