# 5.0试玩计划

状态：待执行。该计划整理5.0交付中的风险，**不是已发生的对局记录，也不是新规则补丁**。

基线：[5.0完整规则](../../versions/5.0/work/v50_rules.md)。交付时的数据/维护/市场情境检查见[原校验说明](../../versions/5.0/outputs/旗舰元年_5.0_修改与校验说明.md)第七节。

## 测试问题与观察

| 主题 | 观察内容 | 记录方式 |
| --- | --- | --- |
| 厂系入口 | 首个厂标取得时点、厂家前置卡滞留、是否被迫只追一种颜色 | 记录卡号、等待回合与被放弃的其他选择 |
| 跨厂路线 | 单厂深入/多厂整合是否都出现自然收益 | 记录实际公司牌与目标，不预设胜率 |
| 供应链 | 是否因担心被抢而调整行动；断货是否迫使改装 | 记录具体零件、回合、替代方案 |
| 世代节奏 | II/III/IV/V在第几次发布前后开放；晚代有没有使用窗口 | 记录解锁回合、采购和成功上市时点 |
| 科技来源 | 打牌、企划、J/R、研究、引擎各贡献多少 | 实际来源分类，不以牌库理论总和替代 |
| 专项竞争 | R提出到下一个玩家完成之间有无合理窗口 | 记录提出档位、剩余档位、其他玩家能否赶上 |
| 现金取舍 | 制造前缺口、融资/整备频率，放大后是否仍紧张或过松 | 发布前后余额、费用和失败原因 |
| 定价 | 每档使用次数、实际改变排名次数、收入/现金差异 | 普通发布与最终发布分开记录 |
| 游戏结束 | 由谁的双轨相遇触发，余下玩家能否完成合理收尾 | 两轨位置、触发回合、额外回合顺序 |
| 易读性 | 类别/厂家混淆，条件与产出混淆，反复查规则处 | 记录具体卡号、页面、原句 |

## 执行原则

分别观察2、3、4人局，不用单一人数的结果替代全部人数。先用同一完整5.0规则跑完，不在一局中途同时改多个参数。发现明确规则矛盾时记录临时裁定并标注，否则对局结果难以比较。

若要比较新方案，另起提案和测试版本；保留原5.0快照。结果同时记录表现与玩家感受，不从一局胜负推出某策略必强/必弱。

日常游玩仍无需纸笔；此处记录是设计测试的可选观测工作，不是加入玩家流程的额外账本。

## 已有记录的边界

原交付保存了1625项定向数据/规则检查、9000个供应状态、1269个单市场结算、2265项成品字段/分页/几何检查，以及科技36的极端存在性见证。它们不模拟完整隐藏信息博弈，不等于同等数量的对局。本次归档只核对文件完整性，不把旧检查当作本次重新执行。
